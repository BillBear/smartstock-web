# Alpha 目标评分卡 OOF 研究计划

## 假设

旧强势标签同时编码“截面收益排名”和“未来路径风险”。如果用连续 `alpha_target_10d` 仅学习特征的相对排序方向，再用原始旧强势/收益/回撤指标评估，Top-K 区分度可能优于按绝对净收益学习方向的基线评分卡。

## 固定不变项

- 数据集、V3 特征契约、开发期日期、五个外层折和 A/C 股票切分不变。
- H1/H2/H3 特征组、60 日动量基线、反向诊断、成本、滑点、path ambiguity 与可交易性处理不变。
- 验证仍使用旧 `label_strong_path_10d` 的 Precision@K/NDCG@K、Top-K 平均收益、交易模拟最大回撤和 bootstrap。
- 不加入风险标签作为特征或验证期扣分；该步骤留给本轮仅在排序目标有效时才进行的后续假设。
- 不读取封存时间留出；不接入生产模型或策略。

## 任务

1. 为训练期评分卡加入预注册方向目标列，默认仍为 `net_return_after_cost_10d`，只允许 `alpha_target_10d` 作为本轮第二个目标。
2. 给既有 OOF 运行器加入严格的方向目标透传和资产列校验；默认行为不变。
3. 新增专用 CLI，正式运行固定 `alpha_target_10d`，输出与净收益基线同结构的方向、OOF、指标、bootstrap、组合回测和候选门槛产物。
4. 对照已有净收益方向评分卡，写出通过或失败的完整证据；不得按结果修改特征、阈值或标签。

## 拒绝标准

- 任一候选必须在至少 4/5 A 折同时改善 Precision@5、NDCG@10、Top5 平均收益、最大回撤，并使 Precision@5 bootstrap 95% 下界大于零；C 象限至少 4/5 折不发生 NDCG 崩塌。
- 否则为 `research_only_failed_gate`，不进行风险模型或生产接入。
- 若本轮通过，也只证明“排序目标值得进入下一项风险解耦研究”，不授权生产接入。
