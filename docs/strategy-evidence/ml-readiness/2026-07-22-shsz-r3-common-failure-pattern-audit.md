截至本审计，当前 SH/SZ R3 研究资产已经否定了三项**固定、无条件、等权特征块**作为 10 日横截面买入排序增量的假设：

三项正式运行均为 `research_only_failed_gate`，`production_integration_allowed=false`。没有新模型、模型 artifact、CoachService、候选池、排序、买卖、止盈止损、仓位、回测执行、API 或页面行为被改变。

这不等于“全市场数据无效”或“机器学习必然无效”。它准确证明了更窄的命题：在同一 R1 标签、五折开发期和 A/C 股票切分下，当前三类静态特征块不能稳定超过既有 60 日复权动量基线。继续在这些已失败的块上翻转方向、删字段、改权重、降低门槛或重跑，属于开发集追逐，禁止执行。

本审计的下一步不是再次训练，而是先补上 R3 当前缺失的、点时正确的市场状态测量，并检验市场状态是否真的解释基线与失败特征组的差异。若该测量假设不成立，应关闭“简单状态条件化可以解决问题”的路线，而不是继续扩展模型。

## 已证实的事实

### 1. 研究宇宙和基本数据规模不是当前主要瓶颈

R3 已使用 5,280 只 SH/SZ 股票和 496 个交易日的特征面板；R1 在完整标签窗口内保留 1,845,361 条可标注样本。北交所按研究宇宙契约排除，不是缺失或抽样事故。H2 的细分资金流最小日覆盖率为 `0.999803`；H3 的点时基本面公告覆盖也通过了共同质量掩码后才参加比较。因此，把 H1/H2/H3 的失败解释成“只用了少数股票”或“数据源没有接入”不符合现有证据。

行数仍不能替代独立样本数。10 日标签相互重叠，核心证据单位是 377 个信号日及其市场阶段，而不是 184 万行彼此独立的观测。

### 2. 60 日动量和成交活跃度是强比较器，但还不是生产级结论

三项运行的第一折中，60 日复权动量的 A 象限 Precision@5 为 `31.76%`、NDCG@10 为 `0.2910`、Top5 成本后平均收益为 `5.78%`；成交额 rank 的 Precision@5 为约 `39%-40%`、NDCG@10 为约 `0.318-0.322`、Top5 平均收益约 `9.63%-9.65%`。这说明标签与评估器并非退化为随机数，当前全市场横截面确实存在可观察的简单排序差异。

但这些数字来自开发期单折，并且 10 日持有窗口互相重叠；它们不能被包装为稳定收益承诺，更不能直接改写生产策略。每个基线仍要在一致样本、状态分层和新的未来时间留出中接受复核。

### 3. 三个失败块的失败形态不同，但共同指向“静态 alpha 与路径风险不可混读”

| 运行 | 相对 60 日动量的 A 象限 NDCG@10 中位差 | C 象限 NDCG@10 中位差 | 关键事实 |
| --- | ---: | ---: | --- |
| H1 | `+0.0173` | `-0.0332` | 个别折局部改善，但只 1 个 A 折、2 个 C 折通过全部门槛；正向等权方向在多数早期折的日 IC 为负，不能据结果反向重试。 |
| H2 | `-0.1281` | `-0.1637` | 高覆盖、残差不为零，但正向 alpha 明显弱；同时 severe-negative rate 较低，证明低风险不等于强正向横截面 alpha。 |
| H3 | `-0.1071` | `-0.1161` | 点时 join 与共同掩码有效，但 18 个字段中 14 个未通过方向/漂移审计；个别折收益或回撤改善不能抵消排序和股票 holdout 退化。 |

H2/H3 对严重负向事件有部分关联，却无法提升强势股排序。这是当前研究中最重要的拆分：**风险辨识、收益排序和可交易路径是不同任务，不能因低风险就把一组字段当作买入 alpha。**

### 4. 标签语义已被审计，但仅换训练目标不是解决方案

历史标签重建证明旧强势/严重风险标签没有写坏。旧强势同时编码截面收益、路径风险和可交易性；`alpha_top10_10d` 则是纯相对排序。此前 2026-07-19 的 Alpha 目标评分卡已经把训练期方向目标切换为连续 `alpha_target_10d`，并保持旧强势、成本、路径和 A/C 评估不变。

该运行仍为 `research_only_failed_gate`：组合评分卡 A 为 `0/5`，所有 A 折 Precision@5 uplift 的 bootstrap 下界为负，H1 只在两折获得训练期方向。故不能再把“目标解耦”当成未检验的修复方案。它仍是正确的语义边界：未来任何候选都应把 alpha 排序、风险和概率校准分开验证；但它尚未提供可用模型。

### 5. 简单市场状态拆分已在旧资产上失败，R3 又缺少可审计的状态字段

此前的状态条件评分卡在旧研究资产上也没有达到 A/C 双侧 4/5 门槛：局部下行折改善没有泛化。这排除了“按状态拆分后自然会成功”的说法。

另一方面，R3 H1/H2/H3 的正式报告均记录 `market_state=unavailable`：R2 没有 materialized 的市场状态字段，运行器没有用事后代理补造。两点必须同时成立：

1. 不得把旧资产的失败无依据外推为 R3 已经完成状态解释。
2. 不得在 R3 未建立点时市场状态契约前，声称 H1/H2/H3 已按市场状态验证。

因此下一步只能先做数据/测量证据，而不是直接给特征加一个“市场状态”名称后再次评分。

## 被否定的解释

以下解释已不足以作为下一轮行动理由：

1. **“再增加更多字段就会更准”**：H2 资金流和 H3 基本面均具备高覆盖或严格 point-in-time 输入，仍未产生稳定增量。字段数量不是证据。
2. **“把差字段删掉或反向即可修复 H1/H3”**：这会使用同一开发期结果选择字段、方向或权重，破坏预注册比较。
3. **“低 severe-negative rate 等于可以买入”**：H2 已直接反例；它的风险率较低但 Precision@5 与 NDCG@10 更差。
4. **“标签有问题，所以结果全部作废”**：标签语义审计确认定义实现一致。标签的复合性质是研究设计约束，不是数据损坏证据。
5. **“训练尚未成功，只要换更复杂的模型即可”**：当前 R3 H1/H2/H3 没有训练新模型，历史模型又存在目标与评估错配。没有新的、经质量验证的条件化信息时，复杂模型只会扩大选择自由度。

## 尚未证实、但可检验的根因

下列是研究假设，不是既成结论：

1. **市场状态异质性**：60 日动量、成交活跃度和三类失败块的有效性可能在趋势、扩散度和波动结构之间不同。R3 尚无点时状态变量，不能确认或否认。
2. **条件交互而非静态主效应**：行业强度、资金流或基本面也许只在特定市场/行业状态下才有增量；当前 H1/H2/H3 检验的是无条件、等权主效应，不足以回答该问题。
3. **执行路径的独立性**：预测相对 alpha 与避免严重路径风险可能需要两个独立 head；现有 H2/H3 的风险诊断只证明研究必要性，没有证明风险 head 可以改善 TopK 决策。
4. **有效独立期数不足**：五个折各约 51 个验证日，并且 10 日标签重叠。一次新的模型比较必须把“日级别时间块”作为推断单位，不能把数百万行当作独立样本。

## 下一步唯一允许的研究：R3 市场状态测量与基线异质性审计

在继续任何模型或特征组合前，先检验以下单一、可证伪命题：

> 使用信号日及以前的 R2 SH/SZ 全市场可观测数据构造固定市场状态后，`adjusted_return_60d` 基线的 TopK 排序结果是否在至少两个状态中存在预注册的、方向一致且可在 A/C 股票集合复现的差异？

这不是新的买入模型，也不改变 H1/H2/H3。它只决定后续是否有理由研究条件交互。

### 输入与点时契约

- 只使用 R2 信号日已存在的全 SH/SZ 行：复权历史收益、有效 OHLC、成交额、涨跌停标志和横截面宽度；可选 `index_daily` 只能作为同日已收盘指数确认，不能作为唯一来源。
- 状态在接入标签、A/C 股票过滤和风险 eligibility 之前，先对全 SH/SZ 有效行按日构造并落盘。
- 每日状态至少要有连续 20 个交易日历史；历史不足、有效股票数不足 4,500、重复键或无效价格时，该日不进入任何比较器。
- 状态定义、边界、日期列表和源码/输入哈希必须在执行前冻结。不得根据 H1/H2/H3 或新结果调整状态阈值。

### 预注册评价与停止规则

1. 先做无标签状态质量检查：每日覆盖率、状态占比、连续性、状态间转移、输入漂移与无未来字段审计。
2. 只比较固定 60 日动量 baseline 在共同 `trade_date + symbol + risk_eligible` 行上的折内结果；不训练候选、不加入 H1/H2/H3、不调仓位。
3. A 与 C 各自的每个状态都报告 P@5、NDCG@10、Top5 成本后收益、Top5 最大回撤、severe-negative rate、有效日期数和 block-bootstrap 区间；不足 20 个验证日的状态仅记录，不作比较结论。
4. 只有同一个预注册状态差异在 A 与 C 都满足以下条件，才允许写一个**新的**条件交互计划：至少 4/5 折方向一致，NDCG@10 差异的 95% 时间块 bootstrap 区间不跨 0，且两侧至少各有 40 个有效状态日。
5. 任一质量门槛失败，或 A/C 不复现时，结论为 `market_state_explanation_rejected`。关闭“条件化能修复当前失败”的路线；不得为了获得差异重新分桶或更改阈值。

即使该测量命题通过，也只允许下一轮研究一个预注册交互，例如“固定 60 日动量只在已固定的趋势/宽度状态下排序”。它仍须采用完全相同的 A/C、成本、滑点、风险掩码和拒绝门槛；通过开发期也只会获得等待新未来留出的资格，不授权生产。

## 不允许做什么

- 不重跑 H1、H2、H3，不删字段、改方向、改权重、改标签或降低 `4/5` 门槛。
- 不把 H2/H3 的低风险率接入风险闸门或买入决策。
- 不访问或重新利用已污染/未冻结的旧时间留出集。
- 不用当前 UI 候选快照代替全市场 R1/R2 研究样本。
- 不因阶段脚本成功或某一折收益较高而声明“模型已更新”或“策略变好”。
- 不修改生产选股、排序、买卖、止盈止损、仓位、回测、API、数据库或前端。
