# 真实换手率端到端实验 T1

## 运行前冻结口径

用户在主线结果 `c20c8fa` 后批准只验证真实换手率替换。此文档是单项研究证据，不是新的治理阶段；不部署、不修改生产服务、参数、模型或数据库。原E2因最终池变化而不可用的结论保留，不改写为成功。

- 代码起点：`c20c8fa`；身份：`default / trend_breakout / medium`。复用已有TuShare daily/daily_basic/adj_factor缓存、baseline-20260906和其绑定的只读观测，不请求新数据。
- 唯一主动变量：冻结预分析池每个quote的`turnover_rate`从原金额代理替换为同日daily_basic实际值。原始市场池、进入分析的股票及顺序、其他字段、权重、风险门槛、ML缺失模式、仓位公式和退出规则全部保持。最终池、排名、动作、评级、计划价格可能由这一个输入自然改变，逐日记录，不伪称只是重新排序。
- 每日先复算旧输入并与保存的decision projection逐字段哈希匹配，再运行替换。原始输入哈希和实际字段与冻结sidecar也必须匹配；不匹配立即失败。真实换手缺失、非有限、负数或零会使整天不可用，零值不重新套金额代理；记录所有排除日期而不按收益选日期。
- 共同评估分母是冻结预分析池（原样保留全部股票），不是两套输出交集。新入选股票正常计算未来标签；不得把旧股票收益复制给新股票。标签用原规则的下一根日线开盘入场和第5/10/20根日线收盘退出，佣金0.0003、滑点0.001；标签不参与生成信号。
- 主统计使用共同池标签完整、两套输出各至少10只且Top10标签完整的相同日期。报告其他日期与缺失率；不足10只不回填。主指标Top5的10日收益、中位数、严重亏损率、共同池超额、NDCG@10；同时给Precision@3/5/10、Lift、MRR、分组收益、Spearman及5/20日敏感性。NDCG理想排序来自同一预分析池。
- 分段延用开发2024-09..2025-08、验证2025-09..2026-02、滚动2026-03..08；共同池20根实际日线标签跨界/未知时整日剔除。历史全部已经查阅，验证段不称真正未见样本。按日期配对，5/10/20日连续日期块、10000次、seed20260830；不按股票行独立bootstrap。既有三个探索加本次共四个假设，采用保守Bonferroni `min(1,4*p)`，不重启单次检验逃避多重探索。
- 市场状态按旧输入全局状态固定分组；buy/watch按各自输出展示，标为动作改变后的描述性子集，不把其差值当独立闸门因果效果。只使用TuShare，all_sources与tushare_only相同且不构成独立验证。
- 原配置、成本、滑点1x/2x、资金、仓位限制、止盈止损/持有期、成交处理全部复用已有研究执行函数，两套输出分别运行。分段采用同一个预分析池日期边界；不重新调优退出规则。公司行动/评分/成交不可验证导致的执行不确定性仍阻止正式Shadow资格，不以账面盯市结果证明实盘收益。
- 拒绝标准沿用：Top5中位数/NDCG/超额必须提高、严重亏损率不恶化、平均净收益正、CI下界正且校正p通过；移除任一日期或股票贡献后改善仍正，辅助周期无反向，两种充分样本市场状态及源一致。缺必要证据标insufficient_evidence；有明确失败标no_shadow_candidate；不自动采用。

## 最终裁决

**T1 = `no_shadow_candidate`。** 独立完整复跑和有证据续算均exit0，完成排名、分段、动作/市场分组和原规则执行诊断。必要样本、字段覆盖、市场状态和统计可计算性检查全部通过，本次不是因为资料不足而没有结论，而是替换后的改善没有通过预先冻结的质量标准。

主要结论：真实换手率使Top5平均10日收益增加0.132846个百分点，但严重亏损率升高、NDCG下降、置信区间跨零，近期滚动段转差。两套Top5平均收益都低于同日100只预分析池。真实字段具有语义价值，但直接代入为金额代理设计的现有规则，不等于提高选股质量；本次既不批准替换上线，也不证明应永久把代理值当作真实换手率。
