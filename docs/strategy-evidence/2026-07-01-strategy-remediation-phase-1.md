# SmartStock AI 策略整改第一阶段记录

日期：2026-07-01

## 结论

本阶段只建设评估、诊断和训练验证门禁，不修改生产选股、排序、买入、卖出、止盈、止损或仓位参数。

这意味着当前提交不会声称收益率提升，也不会把任何新召回规则直接接入生产推荐。后续如要切换生产策略，必须先产出 ranking evaluation、baseline 回测、样本外和 walk-forward 证据。

## 已完成

1. 新增全市场候选漏斗诊断：
   - 从已持久化的全市场快照读取数据。
   - 输出全市场数量、基础过滤数量、多通道召回数量、不同深度分析预算下的覆盖数量。
   - 输出剔除原因和召回通道分布。
   - 样本少于 5000 时标记 `insufficient_coverage`，提示不应生成交易计划。

2. 新增只读诊断接口：
   - `GET /api/coach/diagnostics/universe-funnel?trade_date=YYYY-MM-DD`
   - 只读取快照，不触发策略刷新，不改变候选池。

3. 扩展推荐 API 证据字段：
   - `evidence_status`
   - `sample_coverage`
   - `model_validation_status`

4. 重建 ML 训练验证切分：
   - walk-forward 按完整交易日分组，避免同一交易日同时进入训练和验证。
   - 新增最终时间 holdout，默认 63 个交易日。
   - 新增股票 holdout，默认 20% 股票完全不进入训练。
   - 训练默认样本从 120 只提升到 1500 只，硬上限从 300 只提升到 6000 只。
   - 默认历史跨度从约 18 个月提升到约 24 个月。
   - 训练样本未达到 1500 只、24 个月、100000 条时，默认拒绝训练；调试小样本需显式关闭门禁。

5. 前端智能选股页新增只读漏斗诊断展示：
   - 展示快照日期、全市场数量、基础过滤数量、多通道召回数量和深度分析预算。
   - 诊断接口失败不阻断主推荐页面。

## 未完成

以下事项仍需独立分支、独立评估后再做：

1. 生产候选池从单一 `pre_score` 过早压缩切换为多通道召回 union。
2. 深度分析池 `72 / 150 / 300 / 500` 的离线对比。
3. A/B/C/D 分层阈值和买入动作门禁调整。
4. 新 ML 模型训练、保存和替换当前历史模型。
5. 基于新证据切换生产策略参数。

## 必须补齐的证据

生产策略切换前必须至少产出：

- 历史每日候选池复现。
- 未来 3/5/10/20 日收益标签。
- Precision@3、Precision@5、Precision@10、Recall@10、NDCG@10、MRR。
- Top-K 平均收益和分位收益曲线。
- 样本内、样本外、walk-forward、最终 holdout 和股票 holdout。
- 交易成本、滑点、最大回撤、收益回撤比。
- 不同市场状态下的失效分析。
